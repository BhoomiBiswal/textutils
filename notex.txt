ya koi hacker data chura sakta hai

✅ Why node_modules is included in .gitignore?

👉 The node_modules folder is added to .gitignore because it contains all installed dependencies, which:

Are very large in size, making the repository heavy and slow
Can be easily recreated using npm install from package.json
Are system-generated files, not actual source code
🎯 One-line answer

👉 node_modules is ignored to keep the repository lightweight since it can be regenerated using npm install from package.json.
package.json → tells what to install
package-lock.json → ensures same versions install
node_modules → actual installed files (no need to upload)

Already defined hota hai (package.json me)

Tumhare project me hota hai:

{
  "dependencies": {
    "react": "^18.0.0"
  }
}

🔥 href="/" vs href="#" in JSX
🔹 1. href="/" (Actual navigation)
<a href="/">Home</a>

👉 Matlab:

Browser ko bolo → root page (homepage) pe jao
Real navigation hota hai
Page reload bhi ho sakta hai (normal HTML behavior)

✔ Use when:

Tumhe real page change karna hai
🔹 2. href="#" (Dummy / placeholder)
<a href="#">Click</a>

👉 Matlab:

Kahin jaana nahi hai
Bas same page ke top pe jump karta hai

❌ Real navigation nahi
❌ Bas temporary ya dummy link

⚠️ Problem with #
Page upar scroll ho jata hai (annoying UX)
SEO ke liye bekaar
Accessibility issues

👉 React (SPA) me:

Yeh page reload kar deta hai ❌

Isliye use karte hain:
👉 React Router ka <Link>

<Link to="/about">About</Link>

✔ No reload
✔ Fast navigation

✅ Why we don’t need to import React in function components?

👉 In earlier versions of React (before React 17), it was necessary to write:

import React from "react";

because JSX (like <div>, <h1>) was converted into React.createElement() calls. So React had to be in scope.

🔹 What changed in React 17+

👉 React introduced a new JSX transform.

Now JSX is automatically handled by the compiler (like Babel)
It no longer directly uses React.createElement()
So React import is not required just for using JSX
🔹 Important clarification

👉 It is NOT because you are using a function-based component

✔ Function vs Class has nothing to do with it
✔ The real reason is the new JSX transform

🔹 When do we still need to import?

👉 When using React features like:

import { useState, useEffect } from "react";

✔ Hooks or other APIs still require import

Jab tum likhte ho:

👉 Yeh JSX hai (JavaScript + HTML)
